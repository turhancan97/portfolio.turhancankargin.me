Open-source Python CLI and desktop application for following computer audio or microphone input with live Polish transcripts and English translations via Azure Speech. Features real-time bilingual or English-only captions, floating stay-on-top caption view, pause/resume, connection recovery with gap records, caption arrival timing diagnostics, and opt-in text/JSONL session exports.
